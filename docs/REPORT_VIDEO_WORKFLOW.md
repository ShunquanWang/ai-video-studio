# 报告旁白视频 Workflow

本项目只有一套报告视频渲染器。用户提供报告（文本、Markdown，或可提取文字的文档）
和对应的旁白音频（MP3/WAV/M4A）后，agent 完成分析、转写、分镜、配置、校验和预览。
用户不需要提供分镜表、字幕文件或时间轴。当前 A 股视频是可运行的基准样例。

## 输入与产物

- 报告是事实与画面文案的来源。旁白音频是发声内容和时间的来源。
  两者有冲突时，先核对；不得通过编造数据消除冲突。未核实的行情或政策数字，
  保留“据提供资料，待核实”标记，不写成已核实事实。
- 将音频放在 `public/voiceover/<本次项目>/`，最终使用的文件由
  `src/templates/report-video.json` 中的 `audioPath` 指向。不得使用带片尾提示音的版本。
- `src/templates/report-video.json` 是本次视频的分镜与画面数据；
  `src/templates/report-captions.json` 是与之同序的字幕时间轴。
  两个文件是 agent 的产物，不要求用户编写。渲染器和 CSS 动画无需按报告改动。
- Remotion Studio 入口保持 `AshareReboundReport`；新项目写入以上活动配置后，
  打开 `http://localhost:3000/AshareReboundReport` 预览。

## Agent 执行顺序

1. 读取报告，提取主题、报告日期、视频发布日期、可确认的事实、待核实的数字、
   因果边界与风险提示。视频发布日期若没有给出，采用制作日期并在配置里明示；
   不把报告日期误当发布日期。不得添加报告没有支持的行情、政策或结论。
2. 检查音频实际长度，听查结尾杂音、长静音及与报告的差异。必要时裁剪音频，
   保留原文件。对最终音频运行自动语音识别，获得逐句时间戳；中文可用
   Remotion 的 multilingual Whisper `small`、`language: zh`，或当前环境可用的
   同等 ASR。检查专有名词和数字，**不能用匀速估算替代音频对齐**。
3. 按旁白含义和自然停顿分镜，建议 7-12 镜；画面依次回答“发生了什么、
   证据是什么、如何解释、边界与结论”。将绝对音频时间转换为每个镜头内的
   `startMs` / `endMs`。每个镜头最少 90 帧、最多 900 帧；30 fps。
   片头固定为标题镜头，片尾固定为结论镜头，且后接 45-150 帧“谢谢观看”。
4. 只选 `TitleScene`、`DataScene`、`MetricScene`、`ArchitectureScene`、
   `ExplanationScene`、`ComparisonScene`、`FlowScene`、`OutroScene` 八类模板。
   字段与长度限制以 `src/schemas/report-video.ts` 为准。将每个卡片、图表行和
   提示语绑定到存在的字幕 cue；不能在旁白提到前提前展示完整内容。
5. 写入活动 JSON 和音频路径，运行下面的校验、测试、静态检查和构建。
   在 Studio 检查片头、每个镜头进入前后、长文案、最后一个字幕及谢幕帧。
   若画面溢出、出现空镜头或字幕和音频不符，调整分镜数据并重复检查。
   未经明确要求，不导出 MP4。

## 固定视觉与动画约束

- 固定 1920×1080、30 fps。背景为浅青灰到浅暖灰渐变；信息层使用白色半透明
  毛玻璃、32 px 圆角和高阴影。强调色为青绿，次强调为暖橘。少用可见线条。
- 页面左右留白 96 px，同一镜头的卡片等宽、等高、等间距并对称排布。
  标题最多 22 字；短卡片按具体模板限制为 8-12 字，长要点最多 42 字，详见 schema。
  不通过缩小字体来塞入无关信息；必要时重新分镜。
- 卡片先以 12 帧轻微上移、缩放和淡入出现；文字晚 8 帧开始，仅用 12 帧
  透明度渐变。文字不得横向移动或溢出卡片。隐藏的项目到绑定的字幕时间才出现。
- 数据条在相关字幕后 8 帧开始，用 36 帧渐进增长；轨道和填充条均为完整圆角。
  数字与条形图同时按 cue 露出。卡片内不嵌套卡片。
- 片头只显示标题与发布日期，片尾显示“谢谢观看”、标题、日期及必要提示。
  未经核实的数字保留显式标记；风险提示与数据口径不能被动画遮挡。

## 校验命令

```bash
npm run validate:report -- src/templates/report-video.json src/templates/report-captions.json
npm test
npm run lint
npm run build
npm run dev
```

`validate:report` 校验场景类型、字段长度、cue 引用、字幕不重叠、字幕不超出镜头、
音频实际长度和片尾时长。校验通过不等于事实核实或听感合格；agent 还需听查和预览。
